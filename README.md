Projeto: App de Organização de Tarefas (app-lista-tarefas-android)

Descrição do projeto
O projeto compreende a criação de um aplicativo Android básico voltado à organização das tarefas do dia a dia. Será possível para o usuário adicionar, conferir, modificar e deletar tarefas, promovendo assim uma melhor gestão do seu tempo e de sua produtividade.

Problema que o aplicativo resolve
Algumas pessoas enfrentam desafios ao organizar suas atividades diárias, esquecendo assim compromissos e tarefas de relevância. Este aplicativo oferece uma solução para centralizar tais informações, tornando tudo simples e de fácil acesso.

Plataforma escolhida
Android (desenvolvido com Android Studio)
Linguagem: Kotlin

Interface do usuário (UI)
A interface será minimalista e de fácil entendimento, incluindo:
Tela principal com as tarefas listadas
Botão para inserir nova tarefa
Tela específica para edição de tarefas
Opção de sinalizar tarefa como finalizada

Principais funcionalidades
Inserir tarefas
Modificar tarefas
Apagar tarefas
Sinalizar tarefas como concluídas
Apresentação das tarefas organizada por data ou prioridade

Design (wireframes / esboços)

Tela inicial:
Listagem de tarefas
Um botão com o símbolo “+” para adicionar novas tarefas

Tela de criação/edição:
Espaço para texto da tarefa
Botão de gravação
Escolha de prioridade

Ferramentas utilizadas
Android Studio
Kotlin
GitHub para controle de versão
